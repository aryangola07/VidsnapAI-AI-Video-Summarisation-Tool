# VidsnapAI-AI-Video-Summarisation-Tool
VidsnapAI is a Python + Flask web app that lets users upload video files and receive  AI-generated text summaries — extracting the key information from footage without  watching it manually.  Built to solve a simple problem: video content takes time to consume. VidsnapAI  processes the upload, run, and returns a clean, readable  summary in seconds.

A Flask-based web application that converts video content into structured AI-generated 
summaries. Upload a video — get the key points back as readable text.

## What it does

- Accepts video file uploads via a clean web interface
- Processes audio/visual content through an AI summarisation pipeline
- Returns a structured text summary of the video's content
- Built with Python and Flask — lightweight and easy to self-host
